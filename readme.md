3.What is an ide?

Answer :An IDE (Integrated Development Environment)** is a software that helps you write, test, and fix code more easily. It includes a text editor, tools to check for errors, and features to run your programs—all in one place. Examples include VS Code, PyCharm, and Eclipse.

4.What is JVM?

Answer : JVM (Java Virtual Machine) is a program that runs Java code. It takes Java code, converts it into machine language, and makes it work on any computer. This is why Java can run on different devices without changes.

5.What does LTS stand for?

Answer : LTS stands for Long-Term Support. It means a software version will receive updates, security fixes, and support for an extended period, usually several years.

6.Define syntax.
